# Decisions

## 继续使用 watchlist.json

`watchlist.json` 已经是收盘日报的唯一观察资产配置源。开盘观察继续复用它，避免出现多个 watchlist 互相漂移，也方便新增、删除和调整分组顺序。

## 使用纽约时间判断开盘窗口

美股开盘时间以纽约时间为准，并且纽约存在夏令时和冬令时。代码内部使用 `America/New_York` 判断 09:58-10:12 ET，GitHub Actions 只负责触发尝试，不负责判断交易窗口。

## 暂不做 H5 Dashboard

本次目标是飞书即时提醒和 JSON 沉淀。H5 Dashboard 会引入前端工程、部署、页面状态和权限等额外复杂度，先不纳入本次范围。

## 飞书负责即时提醒，JSON 负责后续沉淀

飞书卡片适合手机端快速阅读，因此控制篇幅并突出观察动作。`data/open_watch/` 的 JSON 保留结构化数据，方便后续复盘、自动化分析或再做页面展示。
